## Main Features
<a id="main-features"></a>

### Core Functionality
- **Multi-Format Support** — PyKaraoke supports a variety of formats including MP3+G, OGG+G, and WAV+G, allowing you to play your favorite karaoke songs seamlessly.
- **Lyrics Display** — The application highlights lyrics in real-time as the song plays, making it easy for singers to follow along.
- **File Management** — Users can add their file collections, and PyKaraoke will automatically search for compatible karaoke formats in specified directories.
- **Compressed File Support** — PyKaraoke can even check the contents of compressed files, ensuring you can access all your karaoke songs.
- **Command Line Conversion** — For advanced users, PyKaraoke includes a feature to convert CDG and KAR Karaoke formats to MPG via the command line.

### Advanced Capabilities
- **Custom Playlists** — Create custom playlists to organize your karaoke sessions and keep the party going.
- **User-Friendly Interface** — The intuitive interface allows users to navigate easily through songs and settings without hassle.
- **Offline Mode** — PyKaraoke can be used offline, making it perfect for impromptu karaoke sessions without the need for an internet connection.
- **Integration with External Players** — If a particular format isn’t supported natively, PyKaraoke can integrate with external players for enhanced functionality.
